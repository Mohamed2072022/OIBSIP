# Tempora — Temperature Converter

A responsive temperature converter built using HTML, CSS, and JavaScript.

## Features

- Convert between Celsius, Fahrenheit, and Kelvin.
- Validate temperature input.
- Prevent temperatures below absolute zero.
- Swap conversion units.
- Clear and reset the converter.
- Display conversion results clearly.
- Responsive layout for desktop and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the `WebDev-L1-TemperatureConverter` folder.
3. Open `index.html` in a web browser.
4. Enter a temperature, select the units, and click **Convert Temperature**.
