# Mohamed Ehab — Personal Portfolio

## Project Overview
A personal portfolio website showcasing my background, technical skills, selected projects, education, and contact information.

This project was prepared as **Level 1 — Task 2: Personal Portfolio** for the Oasis Infobyte Web Development Internship.

## Features
- Responsive personal portfolio layout
- Hero section with introduction and professional title
- About section and technical skills
- Selected projects with external links
- Education and learning background
- Services section
- Contact section with email and GitHub links
- Mobile navigation menu

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Project Structure
```text
WebDev-L1-PersonalPortfolio/
├── index.html
├── style.css
├── script.js
├── profile.jpeg
├── profile2.jpeg
└── README.md
```

## How to Run
1. Download or clone the repository.
2. Open the `WebDev-L1-PersonalPortfolio` folder.
3. Open `index.html` in a web browser.

No installation or build process is required.
