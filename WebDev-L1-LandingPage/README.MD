# TechStart Academy — Landing Page

## Project Overview

TechStart Academy is a responsive landing page concept for a technology training academy that helps beginners and recent graduates explore practical learning paths in web development, Python, and AI fundamentals.

This project was developed as **Level 1 — Task 1: Landing Page** for the Oasis Infobyte Web Development Internship.

## Features

- Responsive landing page layout
- Navigation links to page sections
- Three technology learning-path cards
- Step-by-step training methodology section
- Sample student project showcases
- Career support section covering portfolios, CVs, and interview preparation
- FAQ section using native HTML `<details>` and `<summary>` elements
- Contact link using `mailto:`
- Footer with contact information

## Technologies Used

- HTML5
- CSS3
- Flexbox and CSS Grid
- Responsive media queries

No JavaScript or external UI frameworks are used.

## How to Run

1. Download or clone this repository.
2. Open the `WebDev-L1-LandingPage` folder.
3. Open `index.html` in a web browser.

No installation or build process is required.
